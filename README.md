#Космос: карта связей

Индивидуальный IT-проект — интерактивное веб-приложение для изучения истории космонавтики, которое объединяет информацию о космических аппаратах, ракетах-носителях, космических программах и исторических событиях в единый граф взаимосвязей.
Основная задача — разработать систему, которая позволяет автоматически формировать граф на основе базы данных, визуализировать связи между объектами и исследовать их с помощью алгоритмов обработки графов.
