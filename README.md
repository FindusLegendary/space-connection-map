Космос: карта связей
Интерактивное веб-приложение для изучения связей между космическими аппаратами, ракетами-носителями, космическими программами и историческими событиями. 
Индивидуальный IT-проект — интерактивное веб-приложение для изучения истории космонавтики.
Проект представляет собой веб-приложение, которое объединяет информацию о космических аппаратах, ракетах-носителях, космических программах и исторических событиях в единый граф взаимосвязей.
Основная задача — разработать систему, которая позволяет автоматически формировать граф на основе базы данных, визуализировать связи между объектами и исследовать их с помощью алгоритмов обработки графов.
Основные технологии: веб-разработка, реляционные базы данных, алгоритмы и структуры данных, теория графов и интерактивная визуализация данных.
